**Template record plus the placeholder renderer** (lines 249, 519-552). Note the "empty placeholder removes its whole line" trick, which is exactly how D-11's optional free paragraph and D-24's conditional interest and fee lines should disappear:
```ts
export const DEFAULT_INDEXATION_TEMPLATES: Record<string, { subject: string; body: string }> = { /* nl, fr, de, en */ };

/** Fill {{placeholders}}, drop lines left empty, and tidy blank lines. */
function renderLetter(template: string, vars: Record<string, string>): string {
  let text = template;
  for (const [key, value] of Object.entries(vars)) {
    if (value === "") {
      // A placeholder alone on its line disappears together with the line.
      text = text.replace(new RegExp(`^[ \\t]*\\{\\{${escapeRegExp(key)}\\}\\}[ \\t]*(\\n|$)`, "gm"), "");
    }
    text = text.split(`{{${key}}}`).join(value);
  }
  return text.split("\n").map((l) => l.trim()).join("\n").replace(/\n{3,}/g, "\n\n").trim();
}

export function generateDefaultIndexationEmail(
  params: IndexationEmailParams,
): { subject: string; body: string } {
  const lang = letterLanguage(params.tenantLanguage);
  const template = DEFAULT_INDEXATION_TEMPLATES[lang] || DEFAULT_INDEXATION_TEMPLATES.en!;
  const vars = buildIndexationTemplateVars(params);
  return { subject: renderLetter(template.subject, vars), body: renderLetter(template.body, vars) };
}
```

**One deliberate divergence from the analog:** `indexationEmail.ts` lines 58-80 carry a `LEGAL_REFERENCES` record of statute citations per region. D-09 forbids any statute reference in the formal notice. Copy the *structure*, not that record. A test asserting `/art(icle|ikel)?\.?\s*\d/i` finds nothing in `COPY` is the guard.

### `apps/api/src/routes/payments.ts` (route, request-response)

**Analog:** the `POST /send-reminder` handler in the same file, lines 1291-1345. This is the exact authorisation block to copy, verbatim, including the comment that explains the manager+ rule.

```ts
// Send a rent reminder for a lease's rent in a given month, at a chosen level
// (friendly / formal / final). Works even for rent that is not yet due.
paymentsRouter.post(
  "/send-reminder",
  zValidator(
    "json",
    z.object({
      leaseId: z.string().min(1),
      month: z.string().regex(/^\d{4}-\d{2}$/),
      level: z.enum(["friendly", "formal", "final"]),
    }),
  ),
  async (c) => {
    const userId = getRequiredUserId(c);
    const { leaseId, month, level } = c.req.valid("json");

    // Confirm the user can access this lease's property.
    const leaseRow = await db
      .select({ propertyId: leases.propertyId })
      .from(leases)
      .where(eq(leases.id, leaseId))
      .limit(1);
    if (!leaseRow[0]) return c.json({ error: "Lease not found" }, 404);
    const accessible = await getAccessiblePropertyIds(userId);
    if (!accessible.includes(leaseRow[0].propertyId)) {
      return c.json({ error: "Forbidden" }, 403);
    }
    // T-11-04 / CONTEXT: writes require manager+. Sending a reminder is a write,
    // so a viewer or accountant with property access must still be refused.
    const role = await getUserPropertyRole(userId, leaseRow[0].propertyId);
    if (!role || !hasMinimumRole(role, "manager")) {
      return c.json({ error: "Forbidden" }, 403);
    }

    try {
      // A request authenticated by an API token (MCP tools) is logged as such.
      const viaToken = !!c.get("tokenId");
      const result = await sendManualReminder({
        leaseId,
        periodMonth: month,
        level,
        ownerId: userId,
        trigger: { trigger: viaToken ? "api" : "manual", triggeredBy: userId },
      });
      if (!result.ok) {
        return c.json(
          { error: result.error, ...(result.error === NOTHING_OWED_ERROR ? { code: "nothing_owed" } : {}) },
          400,
        );
      }
      return c.json({ data: result });
    } catch (err) {
      console.error("[Payments] manual reminder failed:", err);
      return c.json({ error: "Could not send the reminder" }, 500);
    }
  },
);
```

Four things to carry across unchanged:
- `getRequiredUserId(c)` then `c.req.valid("json")`, never `c.req.json()`.
- The three-step gate: lease lookup (404), `getAccessiblePropertyIds` (403), `getUserPropertyRole` + `hasMinimumRole(role, "manager")` (403).
- `const viaToken = !!c.get("tokenId")` feeding `trigger: { trigger: viaToken ? "api" : "manual", triggeredBy: userId }`.
- The `{ error, code }` 400 for a typed `ok: false`, and the `{ data: result }` 200 envelope. Keep the `nothing_owed` code so the web layer can show the dedicated message (the overview page already branches on it).

**Imports already present at the top of this file** (lines 1-46), so the new handler adds nothing: `zValidator`, `z`, `eq`, `getDb/leases/properties/tenants`, `getRequiredUserId`, `getAccessiblePropertyIds`, `getUserPropertyRole`, `hasMinimumRole`, `todayInZone`, `NOTHING_OWED_ERROR`. The module-level `const db = getDb();` at line 48 is the file's convention.

**Lower-bar counter-example in the same file, do not copy it:** `POST /:id/ignore` at line 1348 checks only `hasMinimumRole(role, "accountant")` and skips `getAccessiblePropertyIds`. The formal notice is a manager+ write.
