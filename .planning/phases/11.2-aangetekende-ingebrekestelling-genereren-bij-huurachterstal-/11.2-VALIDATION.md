## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 4.1.2 |
| **Config file** | `apps/api/vitest.config.ts` |
| **Quick run command** | `pnpm --filter=@rentular/api test` (the full suite IS the quick command: 85 files, 850 tests, 6.95 s measured) |
| **Full suite command** | `pnpm --filter=@rentular/api test && pnpm --filter=@rentular/api lint` |
| **Estimated runtime** | ~7 seconds for tests, plus `tsc --noEmit` |

No framework install needed. Vitest, MSW and the mocking patterns are all in place.

---

## Sampling Rate

- **After every task commit:** `pnpm --filter=@rentular/api test && pnpm --filter=@rentular/api lint`
- **After every plan wave:** the above plus `pnpm --filter=@rentular/api build` (the tsup ESM path must not rot even though production runs `tsx`)
- **Before `/bm:verify-work`:** full suite green, `tsc --noEmit` clean on `api` and `web`, the blocking DDL checkpoint confirmed by the operator, and the printed-letter visual check done
- **Max feedback latency:** 10 seconds

The suite runs in seven seconds, so no task is allowed to sample a narrower set.
